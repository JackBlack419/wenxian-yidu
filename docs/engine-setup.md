# 翻译接口申请与配置

插件免费。免密钥试用接口与供应商官方 API 是不同服务；配置官方接口时，免费额度、开通要求和收费以供应商当前页面为准。

## 不需要注册：免密钥试用

在“编辑 → 设置 → 文献译读 → 免注册试用”选择必应或有道，运行连接测试。插件能够自动填入地址、发出测试句并给出成功或错误原因。此类入口可能限流、变更或停止服务，不承诺持续可用，也不会自动切换到其他服务商。

| 试用入口 | 实测情况（2026-10-22） | 适合 |
| --- | --- | --- |
| 必应（出厂默认） | 连续 20 段请求全部成功，单次 1–5 秒；依赖必应网页令牌，令牌失效时会自动刷新并重试一次 | 全文、段落对照、双栏 |
| 有道 | 单句正常，但约第 6 次请求后返回「请求频率过快」（`411`）并封锁 20 秒以上，节流也无法避免 | 划词、输入翻译等短文本 |

必应网页接口在中国大陆网络下通常可直接访问，无需代理；如遇持续失败，请先在设置里点“测试当前引擎”，再考虑配置官方接口。

## 小牛官方接口

官方入口：[小牛翻译](https://niutrans.com/)；[接口文档](https://niutrans.com/documents/contents/trans_text)。可参考 [Zotero 中文社区配置说明](https://zotero-chinese.com/user-guide/plugins/translate/niutrans)，界面变更时以供应商控制台为准。

| 步骤 | 谁完成 | 操作 |
| --- | --- | --- |
| 1. 注册或登录 | 用户 | 打开官方平台，使用自己的账户完成登录。 |
| 2. 验证与开通 | 用户 | 完成平台要求的验证码、信息补充、实名认证或翻译服务开通。未要求的步骤无需额外办理。 |
| 3. 获取 API Key | 用户 | 在控制台找到自己的 API Key，复制到插件的小牛密钥框。不要向他人提供账户密码。 |
| 4. 检查与测试 | 插件 | 检查必要字段并翻译一条固定测试句，显示配置结果。 |
| 5. 查询用量 | 用户 | 在供应商控制台确认免费额度、有效期和费用。 |

如果选择了服务商不支持的接口或未开通服务，插件会给出错误提示。不要将其他插件的合作专用入口直接作为通用官方接口使用。

## 有道智云官方接口

官方入口：[有道智云](https://ai.youdao.com/)；[文本翻译 API 文档](https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html)。

| 步骤 | 谁完成 | 操作 |
| --- | --- | --- |
| 1. 注册登录 | 用户 | 完成官方账号登录及验证码。 |
| 2. 创建应用并开通文本翻译 | 用户 | 按控制台提示创建应用、绑定服务，完成供应商要求的认证。 |
| 3. 复制凭据 | 用户 | 复制应用 ID 与应用密钥，分别填入插件字段。不是有道词典账号密码。 |
| 4. 签名与请求 | 插件 | 自动生成 API 签名和语言参数，用户无需自己计算签名。 |
| 5. 连接测试 | 插件 | 翻译固定测试句；无效凭据、未开通、限流和额度问题分别提示。 |

领域翻译和术语表如需供应商额外开通，以其产品文档为准；首版默认使用通用文本翻译。

## 自己的 AI API

1. 选择 AI 引擎。使用预设时，插件填入对应接口地址；使用其他 OpenAI 兼容服务时，填写服务商提供的地址。
2. 填入 API Key 和准确的模型名称。本地模型服务如果不要求密钥，可按界面留空。点击“获取模型”后可搜索、明确选中模型；列表不会自动替换手动输入。
3. 运行连接测试，确认返回的是译文而不是鉴权错误或模型列表。
4. 根据阅读需要调整学术翻译提示词。保留 `{{text}}`、`{{sourceLang}}` 和 `{{targetLang}}` 占位符；需要重新开始时使用“恢复默认模板”。

DeepSeek 的地址与模型以 [官方文档](https://api-docs.deepseek.com/zh-cn/) 为准。本地 Ollama 等服务需要用户先安装并运行模型；插件首版负责连接已有服务，不会自动下载大型语言模型。

## 网络和凭据

需要代理的服务会显示“此功能需要科学上网才能使用”。自定义代理地址的可达性取决于用户自己的部署；不要把所有海外接口一概判断为需要代理，也不要把鉴权失败误判成网络受限。

密钥只在本机宿主安全存储中使用。导出源码、反馈日志和截图时应隐藏密钥。不要为了排错把包含真实凭据的完整请求地址发送给他人。

## 模型列表与托管离线

模型列表使用当前填写的地址与凭据，从同一服务的 `chat/completions` 推导 `models` 地址并保留自定义路径前缀。列表不支持、为空、认证失败或超时时仍可手动输入。列表有此模型不代表能够翻译，仍需运行连接测试。协议参照 [DeepSeek](https://api-docs.deepseek.com/api/list-models/) 与 [Ollama](https://github.com/ollama/ollama/blob/main/docs/api/openai-compatibility.mdx) 官方文档。

用户已有 Ollama 服务仍需自行运行；插件另提供 MTranServer 一键准备，步骤见 [快速上手](user-guide.md)。此功能下载小型 CPU 英中翻译模型，不自动安装大型语言模型。
