# 已知限制

- 当前验收目标是 **Windows x64、Zotero10、英语文字型PDF**。不含OCR；其他平台、旧Zotero和托管离线的其他语言未验收。
- 对照会重排分页/多栏；分屏需完整PDF生成后打开。尚无分屏实时逐段显示、自由分页或语义锚点同步。
- 分屏按滚动比例同步；译文沿用原页区域，长中文或复杂版面可能缩字、拥挤，请回到原PDF核对。
- 对照保留源文已有上下标/MathML，不能修复SDT源已损坏公式，也不提供通用AI输出LaTeX渲染。
- 句段缓存要求配置、语言及规范化文本相同；不同解析器的断句、连字符和公式签名可能不匹配，成品不直接互换。
- 免费网页接口可能限流、变更或失效；插件免费不代表第三方API免费。无真实凭据的接口不声称完成联网验收。
- MTranServer保证本机运行路径，不保证更准确；实测存在术语、否定和单位错误，重要内容必须核对。
- 首次组件及可选离线准备需网络/磁盘空间；百分比属于当前下载阶段，无比例时显示不定进度。Java/解析器下载尚未合并到MTranServer工具栏进度。
- 过窄窗口同时打开多个宿主侧栏时，原生工具栏可能溢出，可关闭多余侧栏或加宽。
- 部分阅读器接口是内部API，宿主升级需复验。历史截图无内容灰框在隔离环境未复现，来源未确认。
